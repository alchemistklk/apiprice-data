# Sync

`node scripts/sync.mjs` (Node >= 18, no dependencies) downloads
<https://apiprice.app/data/prices.json>, keeps only rows with
`channel` in `official_cn` / `official_intl`, keeps the 30 dataset fields
(drops OpenRouter-only `or_*`, `quantized_min_*`, `licensed_cloud_*`), and
rewrites `data/prices.json`, `data/prices.csv` and the `version` /
`date-released` lines of `CITATION.cff` (UTC date of the export's `generated_at`).

It refuses to write (exit 2) if: `schema_version` is not `1.1.0`, `count`
does not match the rows, a dataset field is missing, the export gained a new
non-OpenRouter field, a `model_id:channel` is duplicated, a row lacks
`source_url` / `verified_at` / `currency`, currency does not match channel,
a price is negative, or zero official rows remain.

Options: `--src <url|path>` (or env `APIPRICE_SRC`) to read another export
(e.g. the site's `dist/data/prices.json`); `--check` to exit 1 if files would
change, without writing.

Not scheduled yet. Intended daily use (after the site's daily update and deploy):

    cd /workspace/apiprice-data && git pull --ff-only \
      && node scripts/sync.mjs \
      && git add data CITATION.cff \
      && (git diff --cached --quiet || git commit -m "data: sync $(date -u +%F)") \
      && git push

README statistics are not regenerated by the script; update them when counts change.
